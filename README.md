# Peter Brady | Portfolio

Personal portfolio and CV site, rebuilt from a Bootstrap and jQuery
original into a modern React app.

**Live:** https://peterbrady.ie

## Goals

- Modern, fast, accessible single-page portfolio
- All content driven from one typed data file
- Dark-first design with a responsive layout

## Tech stack

- React + TypeScript (Vite)
- Tailwind CSS v4
- Framer Motion (animations)
- Vitest + React Testing Library
- GitHub Actions (CI/CD)

## Getting started

    npm install
    npm run dev

## Scripts

| Command          | Description          |
| ---------------- | -------------------- |
| `npm run dev`    | Start the dev server |
| `npm run build`  | Production build     |
| `npm run lint`   | Lint the code        |
| `npm run format` | Format with Prettier |
